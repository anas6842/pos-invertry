# POS Inventory System

## Overview
This is a Laravel-based POS Inventory system.

## Setup Steps
1. Clone the repository
2. Run `composer install`
3. Copy `.env.example` to `.env`
4. Run `php artisan key:generate`
5. Set up your database and run `php artisan migrate`
6. Run `php artisan serve`

## Branch Info
- main: stable version
